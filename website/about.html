About SAATH

SAATH brings exercise planning, guided workout logging, custom exercises, body-weight tracking, and progress statistics into a private application a family can operate for itself.

The project inherits code originally created by Duarte Santos. That contribution is preserved as neutral credit; current repository ownership, hosting, support, and distribution are represented only by the SAATH repository.

SAATH is licensed under GNU AGPL-3.0-or-later. Historical contributor credits and release facts are retained in the changelog and Git history.
