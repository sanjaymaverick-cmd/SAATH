Documentation

SAATH is deployed privately for a family or trusted group. Build the images from source, configure HTTPS and backups, then bootstrap the first administrator.

Accounts

The administrator creates member accounts. New and reset accounts receive generated temporary passwords, which must be replaced at first sign-in. Never publish those credentials or the runtime data/ directory.

Self-hosting

Use the repository's self-hosting guide for Docker Compose, TLS, account provisioning, backup, and recovery.

Mobile builds

The Capacitor Android and iOS projects are source projects. Build and sign artifacts for your own devices by following the mobile build guide. No public APK availability is assumed.
