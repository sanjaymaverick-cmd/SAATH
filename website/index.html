SAATH

Progress, together.

A private family wellness and workout application, designed for deployment on infrastructure your family controls.

View sourceRead the docs

Private by design

Family accounts, managed by an administrator

Administrators create member accounts and provide one-time temporary passwords. Each member must choose a private password on first sign-in. Account disabling and password resets revoke active sessions.

Plan

Build weekly schedules and reusable routines from the exercise library or your own custom exercises.

Train

Run guided workouts and log sets, repetitions, weight, time, effort, rest, and personal records.

Understand

Review body-weight history, adherence, activity, strength estimates, muscle balance, and workout statistics.

Self-hosted

Your application and family data stay under your control

Build the web and API images locally with Docker Compose, configure an HTTPS family domain, and protect the runtime data directory and backups. The repository does not promise a public demo, public APK, public support channel, or prebuilt package availability.
